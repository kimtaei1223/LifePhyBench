# Fair confirmatory and static-health results

> Historical scope note (2026-08-27): this document reports the earlier
> continuous-action study. Its conclusions remain valid for that protocol, but
> the health-specific question was subsequently redesigned and tested in the
> separate hierarchical v10 study. See
> [`HIERARCHICAL_THERMAL_CONFIRMATORY_V10.md`](HIERARCHICAL_THERMAL_CONFIRMATORY_V10.md).

## Scope of the primary test

The primary held-out test uses seeds 3000--3009, a 2M-step budget per policy,
and 1,000 task-episode evaluation per policy. It holds the Gym/GAE boundary,
task-boundary marker, and frozen exogenous thermal dose constant. The only
intervention between memory arms is forced LSTM reset at an observed task
boundary.

All ten seeds are retained. The primary report is generated by
`scripts/analyze_fair_confirmatory.py`.

## Primary result

Lifetime memory outperformed task-boundary reset under both endogenous thermal
degradation and the fixed-dose exogenous clock control. The primary result
therefore supports a performance cost from forcing recurrent state reset at a
task boundary in this benchmark.

The endogenous-minus-exogenous interaction was not statistically resolved.
Consequently, the primary campaign alone does not justify the more specific
claim that action-coupled thermal accumulation uniquely requires memory across
task boundaries.

## Static-health robustness analysis

The static-health control was added after the primary campaign and is therefore
reported as robustness evidence, not as part of the primary confirmatory test.
It keeps the thermal wrapper active while fixing its exogenous dose to zero.
Every completed evaluation reported thermal load 0.0 and actuator efficiency
1.0 over 50 lifetimes.

Lifetime memory also outperformed task reset in this static condition. Its
effect was not distinguishable from the fixed-dose exogenous control. This
rules out the claim that the observed reset cost is, by itself, evidence of a
changing hidden health state.

## Permissible claim and next design requirement

The current evidence supports the narrower statement that task-boundary LSTM
reset can harm Recurrent PPO performance, even when Gym termination and GAE
semantics are controlled. It does not yet isolate a memory benefit caused by
persistent physical degradation.

Further Physical AI claims require a redesigned task in which a persistent
physical state changes future transition or reward structure, while alternative
task-boundary context cannot explain the advantage. Any such redesign should
be specified and piloted before starting another full GPU campaign.
