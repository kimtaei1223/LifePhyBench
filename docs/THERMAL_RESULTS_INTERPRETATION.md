# Thermal results: evidence status and corrected confirmatory design

> Historical scope note (2026-08-27): the results below concern the earlier
> continuous-action protocols and should not be generalized to the later
> hierarchical thermal-commitment study. The current held-out result and its
> comparator limitation are documented in
> [`HIERARCHICAL_THERMAL_CONFIRMATORY_V10.md`](HIERARCHICAL_THERMAL_CONFIRMATORY_V10.md).

## What the completed experiments establish

The completed 2M-step runs and independent 1,000-task-episode evaluations are
valid evidence that recurrent PPO can exhibit large seed-dependent instability
under persistent thermal dynamics. The instability is not an evaluation sample
size artifact: the extreme exogenous episode policy remained poor after the
evaluation budget increased from 200 to 1,000 task episodes. Corrected retrains
at the same dose improved substantially but remained heterogeneous.

The result package is generated by `scripts/build_thermal_results_package.py`.
It includes paired seed plots, dose/reward diagnostics, learning curves, CSV
tables, and a machine-readable statistical summary.

## What the completed experiments do not establish

The existing recurrent comparison cannot support a causal claim that lifetime
memory is beneficial, nor an endogenous-specific memory interaction. Two
confounds were found during the audit:

1. The old task-memory arm ended the Gym episode every 100 steps, whereas the
   lifetime-memory arm ended only after 2,000 steps. This changes PPO
   bootstrapping and credit assignment in addition to recurrent memory.
2. The policy-matched exogenous task and lifetime arms used different
   policy-derived doses. Their memory contrast therefore also changes physical
   degradation intensity.

All old runs remain useful as exploratory diagnostics and engineering evidence.
They are not the confirmatory test of the memory hypothesis.

No formal "failure rate" is reported because a catastrophic-failure threshold
was not preregistered. Selecting one after seeing the outcomes would introduce
another researcher degree of freedom.

## Corrected confirmatory intervention

The corrected implementation holds the environment and learning semantics
constant across memory arms:

- all arms expose a 2,000-step physical lifetime as the Gym episode;
- all arms use lifetime-only GAE and bootstrap boundaries;
- all arms observe the same binary task-boundary marker;
- task memory forcibly resets its LSTM at that marker;
- lifetime memory retains its LSTM state;
- both exogenous memory arms use the same frozen dose.

The fixed exogenous dose is `0.008750098932466562`, the pooled median of the ten
2M pilot policy-dose estimates. This value is frozen before using held-out seeds
and is a nuisance calibration, not a fitted result on the held-out campaign.

The held-out seeds are 3000--3009. The primary analysis must retain every seed,
use paired contrasts, and report bootstrap confidence intervals and raw seed
values. Existing seed 1000--1004 results must not be pooled into the held-out
confirmatory test.

The initial fair-pilot command was interrupted before producing any workspace
output. During the interruption audit, the task-reset policy was found to apply
its reset mask during training but not through the `predict()` inference path.
This was corrected by overriding `get_distribution`, and a regression test now
checks that a marked observation produces the same action and next state as an
explicitly zeroed recurrent state. No pre-fix pilot result is valid or retained.

## Required execution order

1. Run a four-cell, one-seed short pilot to verify the controlled implementation.
2. Freeze the implementation and manifest.
3. Run the complete held-out 2x2 campaign.
4. Analyze all held-out seeds without exclusions.
5. Treat dose-grid and alternative-task experiments as robustness analyses.
