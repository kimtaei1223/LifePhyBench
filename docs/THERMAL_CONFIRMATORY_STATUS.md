# Thermal confirmatory experiment status

## Scope note (2026-08-27)

The sections below describe the earlier continuous-action 2M-step thermal
study and its outlier retest. They remain as audit history. The newer v10
hierarchical thermal-commitment study used a separate frozen protocol, 20
held-out training seeds, and a static zero-dose factorial control. Its primary
learned-versus-learned contrast passed, subject to an important task-reactive
comparator limitation. The authoritative current report is
[`HIERARCHICAL_THERMAL_CONFIRMATORY_V10.md`](HIERARCHICAL_THERMAL_CONFIRMATORY_V10.md).

## Valid primary analysis

The primary 2M-step comparison uses five paired seeds and independent
1,000-task-episode reevaluation for every policy. The primary analysis retains
all seeds, including unstable policies.

## Invalidated robustness run

The four runs under `outputs/thermal_exogenous_outlier_retest` used dose values
copied from the earlier 1M calibration instead of the 2M calibration. They must
not be used as evidence about the 2M outliers.

The incorrect and correct values are:

| Source seed | Incorrect retest dose | Correct 2M dose |
|---|---:|---:|
| 1002 | 0.0285865943 | 0.0343727173 |
| 1004 | 0.0335475200 | 0.0191310221 |

The invalid runs are preserved for auditability. Corrected robustness runs are
generated by `scripts/run_outlier_retest_campaign.py`, which reads the dose
directly from `outputs/thermal_policy_matched_dose_long.json`.
